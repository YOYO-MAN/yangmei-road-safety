# 楊光梅好、安全第一

桃園市立楊梅高級中等學校｜高二交通安全充實課程

分組活動版

「楊光梅好」取自校名，諧音「陽光美好」——那是你接下來的青春與未來；「安全第一」，是守住這一切的前提。這裡整理了課堂上的兩個重點，讓你課後複習、自己練習。

以校內課程資料為主要來源，完整來源對照見 materials/source-notes.md。靜態網站可使用 GitHub Pages。影片採原發布者連結與原播放器。
