# 楊梅高中交通安全充實課程

[開啟交通安全課程網站](https://yoyo-man.github.io/yangmei-road-safety/)

放學路上的安全選擇：新聞判讀、通學安全、小組情境任務與五題檢核。

網站及學生教材以課程內容與活動名稱呈現，無課程時長或節數標示。

## 網站內容

- `index.html`：課程首頁。
- `app.js`、`course-data.js`、`style.css`：互動內容、資料與版面。
- `hero.png`：原創 AI 教學示意插畫，非真實校園。
- `materials/`：教師計畫書、教師簡報、學生活動單、海報與影片來源清單。

## GitHub Pages

將本資料夾放在儲存庫根目錄，於 Settings → Pages 選擇 Deploy from a branch，分支 `main`、資料夾 `/ (root)`。本網站為靜態網頁，無須安裝套件。
